# 104 人才快速媒合

目前版本：0.1.3

這是一個 Chrome Manifest V3 擴充功能。你用自然語言描述理想人才後，它會讀取目前 104 VIP 人才列表中每位人才的詳細頁資料，交給 TypeSafe Jev 評估，並把契合百分比直接顯示在人才卡片上。

## 安裝

1. 在 Chrome 開啟 `chrome://extensions`。
2. 開啟右上角的「開發人員模式」。
3. 選擇「載入未封裝項目」，選取本專案資料夾。
4. 登入 `https://vip.104.com.tw/` 並進入人才列表。
5. 點擴充功能圖示，填入人才描述與 TypeSafe API key，再按「儲存並評估目前列表」。

## 行為與隱私

- 登入完全由 104 網站處理；擴充功能不保存 104 帳密。
- API key 與人才描述放在 `chrome.storage.local`，只存在本機 Chrome 使用者設定檔；它們不會同步。
- 評估時，擴充功能會從 104 登入狀態下的履歷 API 讀取職涯、技能、學歷與求職條件；姓名、Email、電話、地址、照片及人才識別碼等獨立欄位不會送給 TypeSafe，履歷自由文字中的 Email 與台灣手機號碼也會遮蔽。篩選後的媒合資料、你的需求與 API key 會直接送到 `https://api.typesafe.ai/v1/systemone`。
- 契合度是 Jev 五級 Score 的機率加權位置換算成 0–100%，不是錄用結論。滑鼠停在徽章上可看判斷信心與資料來源。
- 履歷 API 無法讀取、回傳資料不足或登入失效時不會送出評估，該人才會標示「詳細頁失敗」，避免用錯誤資料產生契合度。

## 已知限制

- 104 是第三方網站，若它調整人才卡片或詳細頁的 HTML，`content.js` 中的偵測規則可能需要更新。
- 擴充功能只評估目前已載入在頁面上的人才，最多 50 人；需要更多人時請換頁後再執行。
- 首版未串接真實 104 帳號及付費 TypeSafe API，因此自動測試只涵蓋分數換算、文字清理與 Jev 請求組裝。
