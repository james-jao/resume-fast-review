# 104 人才快速媒合

目前版本：0.3.0

這是一個 Chrome Manifest V3 擴充功能。你用自然語言描述理想人才後，它會讀取目前 104 VIP 人才列表中每位人才的詳細頁資料，交給 TypeSafe Jev 評估，並把契合百分比直接顯示在人才卡片上。

## 安裝

1. 在 Chrome 開啟 `chrome://extensions`。
2. 開啟右上角的「開發人員模式」。
3. 選擇「載入未封裝項目」，選取本專案資料夾。
4. 登入 `https://vip.104.com.tw/` 並進入人才列表。
5. 點擴充功能圖示，填入人才描述與 TypeSafe API key，再按「儲存並評估目前列表」。

## 邀約紀錄標示

- 已連接你提供的[約邀紀錄](https://docs.google.com/spreadsheets/d/1FA_iLasxq_048kEopxAjPeXZAA4gdo-XDTGkrZLEFIs/edit#gid=202392536)。開啟 104 後會自動同步，頁面保持開啟時每五分鐘檢查一次；也可以在擴充功能按「立即同步邀約表」。
- 列表卡片與詳細頁會顯示同名紀錄的「邀約狀況、一面結果、二面結果」。不必啟動 AI 評分或提供 API key。點擊標示可開啟原表相應列，滑鼠停留可看各筆狀態與表格同步時間。
- 表格只有姓名，因此「同名邀約紀錄」仍須確認為同一人；遮蔽姓名會標為「疑似邀約紀錄」。多筆同名紀錄會顯示各筆狀態，不依沒有年份的日期猜測最新一筆。未連繫上、不邀約等狀態也照實顯示，不把所有表格紀錄視為已邀約。
- 同步失敗會在擴充功能顯示原因，保留上次成功資料並在卡片註明「舊資料」。沒有標示表示目前快取未匹配，不能據此保證未曾邀約。
- 姓名與邀約狀態只在本機比對、快取，不會傳給 TypeSafe。擴充功能唯讀取得表格 CSV，不修改 Google 表格。只新增 `docs.google.com` 讀取權限，請求固定使用上方指定的邀約表。表格必須允許目前的 CSV 讀取；若分享設定變更或存取遭拒，同步會失敗。
- 升級時請載入 `dist/104-fast-review-v0.3.0` 資料夾，或解壓 `dist/104-fast-review-v0.3.0.zip` 後載入。若已從專案根目錄載入，請在 `chrome://extensions` 按重新載入，再重新整理 104。

## 行為與隱私

- 登入完全由 104 網站處理；擴充功能不保存 104 帳密。
- API key 與人才描述放在 `chrome.storage.local`，只存在本機 Chrome 使用者設定檔；它們不會同步。
- 評估時，擴充功能會從 104 登入狀態下的履歷 API 讀取職涯、技能、學歷與求職條件；姓名、Email、電話、地址、照片及人才識別碼等獨立欄位不會送給 TypeSafe，履歷自由文字中的 Email 與台灣手機號碼也會遮蔽。篩選後的媒合資料、你的需求與 API key 會直接送到 `https://api.typesafe.ai/v1/systemone`。
- 契合度是 Jev 五級 Score 的機率加權位置換算成 0–100%，不是錄用結論。滑鼠停在徽章上可看判斷信心與資料來源。
- 成功評估的結果會保存在本機。列表往下捲載入更多人才後，再執行一次會略過相同人才描述下已有分數的人才，從新載入的人才接續評估。
- 從列表進入人才詳細頁時，右下角會顯示該人才在目前人才描述下最近一次的契合度與判斷信心。
- 直接從書籤、分享連結或其他入口開啟人才詳細頁時，也能在擴充功能中啟動單一人才評估，不需要先經過人才列表。
- 履歷 API 無法讀取、回傳資料不足或登入失效時不會送出評估，該人才會標示「詳細頁失敗」，避免用錯誤資料產生契合度。

## 已知限制

- 104 是第三方網站，若它調整人才卡片或詳細頁的 HTML，`content.js` 中的偵測規則可能需要更新。
- 擴充功能只評估目前已載入在頁面上的人才，最多 50 人；需要更多人時請換頁後再執行。
- 首版未串接真實 104 帳號及付費 TypeSafe API，因此自動測試只涵蓋分數換算、文字清理與 Jev 請求組裝。
- 評估快取存在目前 Chrome 使用者設定檔，未依 104 公司帳號分區；若在同一個 Chrome 設定檔切換不同公司帳號，請使用不同 Chrome 設定檔，避免看到前一帳號留下的本機契合度。
